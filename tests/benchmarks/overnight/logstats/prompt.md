Write a command-line tool logstats.py that reads a web server access log in Common Log Format (a file path argument, or standard input when no path is given) and prints a report: the total number of requests, the five most requested paths, the count per HTTP status code, the 95th percentile of the response size in bytes, and the busiest minute with its number of requests. Lines that are not valid log lines must be counted and reported as malformed, never crash the tool. A `-` for the size field means zero bytes. Add a sample log file with at least 40 lines that includes malformed lines and a `-` size, and pytest tests that check the numbers against values you worked out by hand. Run the tests.
