Build the members screen of an admin tool for Harbour Climbing Club, a community climbing gym, for the front-desk staff who look people up all day. It shows a table of members with name, membership type (monthly, annual, day pass), status (active, frozen, expired), last visit and next payment date, with search, filters for membership type and status, selecting several rows to act on them together (freeze, send a reminder, export), and paging. Use realistic sample data (at least twelve members) written into the page. Put it in project/index.html with project/style.css (plain HTML and CSS, JavaScript only where it adds something). It must work on a phone. Look at it in a browser at desktop and phone width before you finish.
